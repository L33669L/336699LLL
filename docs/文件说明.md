# 文件说明

| 文件 | 用途 |
|---|---|
| send_goal.py | 命令行参数、调用导航、保存 JSON |
| navigation/navigator.py | Action 等待、执行、取消和终态记录 |
| navigation/pose_reader.py、ground_truth.py | TF 与 Gazebo 位姿采集 |
| navigation/sensors.py | scan/odom 消息统计和最近消息年龄 |
| navigation/result.py、metrics.py、config.py | 结果对象、数学计算、测试工具配置 |
| config/test_config.yaml、rosbag_qos.yaml | 测试超时/阈值、录制静态 TF 的 QoS |
| run.sh、check.sh、stop.sh、env.sh | 启动、管理器检查、停止、ROS 环境 |
| sim.sh、nav.sh、rviz.sh、*.launch.py | 现有 baseline 启动链 |
| initial_pose.py、ready.py、clock_relay.py | 初始化、就绪检查、时钟转发 |
| verify.py、health.py、soak.py、audit.py | 基线诊断；soak/audit 是手工工具，不在默认 pytest 中 |
| make_params.py、*.baseline.yaml、baseline.rviz | 参数生成工具与当前配置；生成工具会覆盖本地配置，正常运行无需执行 |
| tests/ | 纯函数、模拟通信、真实 ROS2 / Nav2 集成测试 |
| results/、evidence/、archive/ | 当前测试、基线输出、历史证据 |


公开仓库保留上述源码和配置；本地 results 历史批次、evidence、archive、编辑器配置与原始 bag 不上传。公开证据范围见 [公开证据说明](公开证据说明.md)。历史文件原地保留，本次修改前文档另存本地 archive/publication-20260929-before/。
